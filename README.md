# 蜡笔小新 · 经典片段

打开链接就自动播放的单视频页面，右下角带 `rzh` 水印。

## 它是什么

一个纯静态单页：整页只有一个视频窗口，进页面即自动播放，不需要点播放键。
视频通过哔哩哔哩官方播放器以 iframe 内嵌，本仓库不托管、不转存任何视频文件。

关于自动播放：浏览器不允许"首次访问 + 带声音"的自动播放，所以播放器会自动开播，
但可能是静音状态，点一下画面右下角的喇叭即可开声音。这是浏览器规则，无法绕过。

## 目录结构

```
index.html          页面结构
assets/styles.css   蜡笔涂鸦风格的样式 + 角落水印
assets/app.js       播放器加载与链接解析
assets/clips.js     片单数据（想换片段改这里）
```

## 换片段

改 `assets/clips.js` 里的数组即可，第一条就是默认播放的片段。`bvid` 取自视频链接
`https://www.bilibili.com/video/BVxxxxxxxxxx/`。把 `bvid` 放到数组里，
页面就会用它生成内嵌播放器地址。

## 链接直达某一段

- `https://<你的域名>/#BV1Zs4y197X1` 打开就播这一段
- `https://<你的域名>/?v=BV1Zs4y197X1` 同样效果
